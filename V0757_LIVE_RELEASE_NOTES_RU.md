# v0.7.57 — LIVE / GitHub Release — 4 ноября 2026

Подтверждено: все 7 активных торговых движков обновлены на v0.7.57; LIVE installer завершился `V0757_ALL_LIVE_PASS`. Штатный Telegram `/latency` за 60 минут подтверждён пользователем.

## Изменения (строго три согласованные задачи)
1. Elective CANCEL-only: отдельный `SingleOwnerCancelTransport` обновляет простаивающий HTTPS-сокет перед единственным добровольным POST (порог 15 секунд); без blind retry или изменения торговой стратегии. Добавлены безопасные диагностические события по idle/reconnect/ошибкам.
2. `/latency`: обнаружение работающих grid-сервисов динамически, без жёстких BOTS или устаревшего версионного пути CLI.
3. CHANGELOG: восстановлена история v0.7.50–v0.7.53, добавлены записи последующих версий.

## Известные ограничения
- `/latency8h` (480 мин) сейчас не работает: CLI ограничен диапазоном 15–180 мин. Это известно и оставлено без изменения по решению владельца.
- 12-часовая LIVE-эффективность подавления stale CANCEL пока не подтверждена после обновления; нужен последующий анализ telemetry.
- Длинные редкие задержки Reader/StatsWorker остаются вне scope v0.7.57.

## Контроль безопасности
