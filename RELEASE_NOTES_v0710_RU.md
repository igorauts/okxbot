## OKX Grid Bot v0.7.10 — новые инструменты и точные цены

- Поддержка BTC / ETH / SOL / **NEAR / ZEC / SUI** (`USDT-SWAP`), новый мастер `okx_setup0710.py`; старый `okx_setup068.py` оставлен для совместимости.
- Исправлено округление торговых цен до двух знаков: теперь BUY, attached TP и идентификаторы грид-уровней используют точность `tickSz` (особенно важно для NEAR/SUI).
- Исправлен встроенный `run_tests()` для инструментов с тремя и четырьмя знаками после запятой.
- Исправлено отображение шага, TP, защиты BUY и цены в интерфейсе настроек, обновлена граница real TP до 150.
- Для **новых** экземпляров после подтверждённого `PANIC_DONE` `ExecStopPost` отключает автозапуск завершённого бота и останавливает/отключает его собственные Burst/Execution-наблюдатели. Общий Telegram Monitor не затрагивается.
- **99/99 офлайн-тестов**; LIVE ZEC и SUI подтвердили работу реальных BUY/TP. Отключение торгового сервиса после PANIC подтверждено LIVE, а остановка двух **работающих** наблюдателей — только mock-systemd тестами, не LIVE.
- GitHub Release не обновляет работающие экземпляры. Исторический `install.sh` **не устанавливает v0.7.10**.
