# OKX Grid Bot v0.6.9

Версия с исправлениями безопасности торгового движка.

Основные изменения:
- Корректная обработка отказов OKX.
- Общий AUTO SOFT STOP при нехватке маржи.
- Штатная отмена BUY при аварийной остановке.
- Продолжение обслуживания реальных и виртуальных TP.
- Ручное возобновление после аварийного SOFT STOP.
- Защита от блокировки TP неопределёнными BUY.

Общий аварийный флаг:
`/var/lib/okxbot/account_soft_stop.json`

Оба бота должны использовать общий каталог.

При аварийном SOFT STOP возобновление торговли
возможно только после ручной разблокировки
и отдельного перевода каждого бота в RUN.

Тесты:
`python3 test_v069_safety.py`

История торговли и SQLite-базы сохраняются.
