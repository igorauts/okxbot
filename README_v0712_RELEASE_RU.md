# v0.7.12 — описание публикации

`okx_bot0712.py` — актуальный торговый движок. Исторические файлы старых движков оставлены в репозитории для совместимости менеджера; это не несколько разных LIVE-версий.

Обновлённые модули со старыми именами: `okx_latency_v0711.py` и `okx_execution_observer0711.py`. Они входят в v0.7.12 и совпадают по SHA256 с установленным релизным каталогом на VPS на момент подготовки публикации.

`install.sh` относится к прежним поколениям программы и **не предназначен** для автоматической миграции работающих 0.7.11 → 0.7.12. Миграция существующих LIVE-ботов требует сохранения state и SQLite, контроля systemd и сверки биржевых ордеров. GitHub ZIP — исходники, не инструкция автоматически запустить реальную торговлю.

`Latency Diagnostics` встроен в движок как асинхронный сборщик; отдельная служба не нужна. UI-экран менеджера пока не добавлен.
