# OKX Grid Bot v0.7.9 — BUY Refill Priority

Выпуск 17 октября 2026 года. [GitHub Release](https://github.com/igorauts/okxbot/releases/tag/v0.7.9).

## Поведение BUY и TP

Если активных BUY меньше цели, бот сначала восстанавливает BUY после успешной REST-сверки ордеров/позиции, проверки покрытия SELL и защитных ограничений. Избыток SELL TP сам по себе не блокирует BUY.

Избыточные реальные TP могут временно составлять 15, 25, 55 и более. Очистка — отмена по одному после 1,5 секунды без появления новых TP с повторной сверкой. При 150 TP действует немедленная защита, новые BUY запрещены. При 145–149 TP резерв под attached TP ограничивает количество новых BUY. Превышение 150 TP считается аварийной ситуацией, а не автоматически восстанавливаемым штатным состоянием.

Сохранены BUY target +5 buffer, post-only, no-churn, проверка свежего BID, контроль свободных уровней, общее число ордеров и запрет повторного неопределённого POST. Политика `virtual_escape` не менялась.

## Мониторинг

В релиз включены `okx_execution_observer079.py`, `okx_monitor079.py` и совместимый `okx_monitor_compat078.py`. Для v0.7.9 больше не используется fallback к контроллеру v0.7.4. Наблюдатели read-only, не выполняют торговых запросов.

## Проверки и границы

Проверены 80 офлайн тестов: v076 — 45, v078 — 13, v079 — 9, поведенческие стресс-тесты — 13. Параллельная работа реальной биржи и все возможные рыночные сценарии этими тестами не гарантируются. SHA256 движка: `99ebb889226d9fe41544268fa15ecf59f9dd5285244a3d92e4b70b8a835935b0`.

Публикация не меняет LIVE службы. Старый `install.sh` — исторический установщик v0.7.3, **не использовать для v0.7.9**. Автоматическая остановка observers/отключение bot systemd после PANIC_DONE и поддержка NEAR/ZEC/SUI **не входят** в v0.7.9; запланированы для следующей версии.
