# OKX Grid Bot v0.7.60 — S1–S3 + D1 — 5 ноября 2026

RELEASE_VERSION=0.7.60 · ENGINE_VERSION=0.7.60 · RELEASE_KIND=engine.

- **S1 Reader watchdog:** постоянный systemd `Type=simple`, безопасный цикл 20 секунд, сохранена ограниченная политика восстановления Reader; timer отключён. `deploy/reader` содержит обновлённый шаблон service.
- **S2 Resource Sampler:** динамический `list-unit-files` кешируется на 1 час, вместо опроса каждую минуту. Никакого хардкода списка ботов.
- **S3 Observers:** один combined observer на торгового бота вместо двух отдельных процессов; сохраняются оба потока наблюдения `burst` и `execution`, соответствующие summary/cursor, и менеджер управления observer.
- **D1 BotDrawdownSampler:** все 5-секундные расчёты сохраняются; новый худший максимум записывается немедленно с durable fsync, обычное текущее значение пишется не чаще 60 секунд. При crash последние обычные samples могут быть потеряны; зафиксированный максимум — нет.
