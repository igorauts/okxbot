# OKX Grid Bot v0.7.13 — Management & monitoring hotfixes

**Hotfix поверх v0.7.12.** Торговый движок остаётся `okx_bot0712.py` (`VER=0.7.12`), формат state и торговая стратегия не меняются. Новый движок `0713` не создаётся, live-процессы не рестартуются.

## Исправлено

- **SOFT STOP → RESUME:** при ошибке маржи OKX `51008` включается общая блокировка аккаунта. Менеджер теперь показывает её и запрещает обычный Resume, пока блокировка не снята. Новый пункт «Общая остановка аккаунта — восстановление (SOFT)» после проверок состояния всех экземпляров и явного подтверждения оператора снимает общую блокировку; сами боты остаются в SOFT до индивидуального Resume.
- **Три бота на одном аккаунте:** процедура восстановления проверяет все три настроенных экземпляра ETH079, ZEC0710, SUI0710-2, их `SOFT_STOPPED` и отсутствие незавершённых BUY. Менеджер **не подтверждает свободную маржу**: оператор проверяет плечо и доступную маржу на OKX вручную.
- **Постоянные имена наблюдателей:** службы теперь `observer-okx-grid-<slug>-burst.service` и `observer-okx-grid-<slug>-execution.service` без версионного суффикса. Обновлён lifecycle-handler для распознавания новых и старых имён.
- **Статус и управление наблюдателями:** `okxbot` корректно показывает ON/OFF для постоянных unit-файлов и не запускает дубль старого `-v0711` наблюдателя.
- **Latency:** размер одного файла встроенной телеметрии увеличен с 16 до 256 МиБ; два файла позволяют сохранять до 512 МиБ. Для уже запущенного Python новый предел вступит в силу только после штатного перезапуска торгового процесса; этот выпуск его не выполняет.

## Состав патча и установка

Прикреплённый `okx_hotfix_v0713.zip` содержит **только изменённые файлы**, release notes и контрольные суммы; это **не полный установщик** и не архив для замены каталога работающего бота. GitHub исходный код по тегу содержит полную историю репозитория по правилам GitHub.

На действующем VPS изменения управления уже установлены. Во время публикации не менялись systemd, торговые боты, ордера, конфигурации, state и SQLite.

⚠️ Существующая команда ручного сброса привязана к конкретным трём экземплярам указанного аккаунта; **не предназначена для произвольной многоботовой инсталляции без адаптации и проверки**. Стабильные systemd unit-файлы являются частью настройки VPS и не включены в пакет как универсальный автодеплой.

Наблюдатель с историческим именем `okx_execution_observer0711.py` уже поддерживает state v0.7.12 в опубликованной v0.7.12; повторно не менялся.
