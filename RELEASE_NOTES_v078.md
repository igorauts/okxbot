# OKX Grid Bot v0.7.8 — Terminal Accounting & Monitoring Reliability

**Важное:** v0.7.8 объединяет неопубликованные на GitHub изменения v0.7.7 и последующие исправления v0.7.8. ETH077 и SOL077 в LIVE были успешно переведены на v0.7.8 после GET-only сверок; четыре наблюдателя и Telegram активны. GitHub Release сам по себе не меняет их состояние.

### Accounting and final bot stats

- `PANIC_DONE`: подтверждённый итоговый торговый PnL = исходный GRID PROFIT + остальные реализованные закрытия + результат PANIC SELL по фактическим исполнениям/комиссиям. GRID PROFIT не перезаписывается. При недостаточных биржевых данных окончательный PnL не публикуется.
- `RETIRED`/HARD: сохраняется исторический снимок оставшейся позиции и нереализованного PnL на момент остановки; финальный реализованный PnL не вычисляется.
- CLI и Telegram показывают **полную прежнюю статистику** плюс терминальный блок, а не заменяют отчёт сокращённым.
- GET-only повторный расчёт старых завершённых экземпляров и надёжная проверка незавершённых терминальных отчётов.

### Manager, Telegram and observers

- Менеджер выбирает новейший движок по версии и манифесту независимо от возраста файла мастера создания.
- Telegram `/status` — только активные экземпляры; `/status NAME` — адресная историческая статистика.
- Наблюдатели v0.7.8 вычисляют длительности неполной BUY-сетки по временным меткам **журнала движка**, отдельно помечая расхождения с периодически сохраняемым JSON.
- Подтверждённая частичность BUY отделена от простого обнаружения прикреплённого TP: `ATTACHED_TP_DISCOVERED` / `PARTIAL_ATTACHED_TP_DISCOVERED`.
- Burst/Execution Observer — локальный read-only процесс без дополнительных OKX API запросов; низкие приоритеты CPU/IO, лимиты ресурсов, буферизация диагностических событий.

### Guarantees and limitations

- Сохранены v0.7.6 и предыдущие исправления r1/r2 no-churn.

- Схема архива содержит необходимые движки 0.7.6/0.7.7/0.7.8, менеджер, манифест, терминальную статистику и мониторы 0.7.8. Используется Python 3 с зависимостями из `requirements.txt`.
