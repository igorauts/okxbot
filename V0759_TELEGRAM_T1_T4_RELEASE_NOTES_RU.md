# v0.7.59 — Telegram T1–T4 maintenance — 5 ноября 2026

RELEASE_VERSION=0.7.59; RELEASE_KIND=maintenance. Торговый ENGINE_VERSION остаётся 0.7.57.

## Изменения Telegram

- **T1:** отдельный поток getUpdates c 25-секундным long polling, HTTPS keep-alive и повторным использованием SSLContext. Очередь команд с ограничением размера; offset обновляется только по завершении обработки и сохранению состояния.
- **T2:** отдельный worker для `/status`, `/full`, `/latency`, `/help`, чтобы долгий запрос баланса не удерживал основной цикл safety-проверок.
- **T3:** персистентное состояние Telegram пишется при реальном изменении; важные инциденты продолжают использовать durable outbox и fsync.
- **T4:** опрос состояния systemd не чаще одного раза за 15 секунд; пятсекундные safety/heartbeat/alert-проверки оставлены без изменений.
