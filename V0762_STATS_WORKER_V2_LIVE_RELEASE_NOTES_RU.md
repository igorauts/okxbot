# v0.7.62 — StatsWorker v2: LIVE engine rollout — 6 ноября 2026

RELEASE_VERSION=0.7.62 · RELEASE_KIND=engine · ENGINE_VERSION=0.7.62.

## Изменения

- Инкрементальный StatsWorker v2: единый источник финансов, контроль полноты fills, bounded HOT-часть, архивирование закрытых циклов, durable checkpoint. Проверки не подтверждают отсутствующие исполнения и сохраняют fail-closed.
- Шесть дополнительных `okx_stats_v2_*` модулей и обновлённые зависимости движка в `engine_manifest.json`.
- Торговая стратегия, защитные режимы BUY/TP/MARKET/EXIT, лимиты ордеров и механизм Reader не менялись ради этого релиза. Рабочие модули Telegram v0.7.61 сохранены.

## Проверено ДО GitHub-публикации

- Защищённый переход всех 8 LIVE-ботов: ZEC, BEAT, DOOD, INIT, WLD, NEAR, BLUR, BTC; BTC обновлён последним. Установщик для каждого подтвердил SOURCE SHA, GET-only аудит, корректность закрытых циклов, свежий heartbeat. Рестартов после перехода не наблюдалось в финальном снимке.
- Все 8 ботов опубликовали подтверждённые снимки StatsWorker v2. BLUR после обработки большой истории подтвердил прогресс архива и публикации.
- ZEC: независимый FULL-паритет на общем офлайн-снимке — PASS (25 744 исполнения в зафиксированном прогоне).
- BEAT: паритет замороженной истории/доказанных закрытых циклов — PASS; активные незавершённые HOT-циклы этой проверкой не доказаны. Статистика нового BEAT успешно публиковалась после однократной ручной инициализации anchor.
- Офлайн preflight кандидата и регрессионные тесты были выполнены до LIVE. В процессе GitHub-публикации никакие тесты не запускаются.

## Известное ограничение

- У нового бота StatsWorker v2 не создаёт автоматически исходный `state/grid_reference.json`, который ранее формировался FULL-расчётом. На BEAT отсутствие anchor привело к `STATS_V2_NOT_READY` и Telegram `н/д` до безопасного однофайлового восстановления из сохранённой конфигурации. **Это не исправлено внутри v0.7.62.** Для следующих новых ботов требуется отдельный проверенный bootstrap/ремонт anchor; не подставлять значения, не ослаблять проверки. Постоянное исправление — следующий релиз.
- Успешный паритет зафиксированных историй не является доказательством каждой незавершённой HOT-операции. Любое несоответствие обрабатывается fail-closed.

## Границы публикации

- GitHub-only: без OKX API, LIVE-записей, остановок/рестартов сервисов и выполнения тестов. В репозиторий вносится только SHA-pinned пакет v0.7.62 плюс настоящие release notes/README/CHANGELOG; торговый код не переписывается.
- `main` и один annotated tag пушатся атомарно. При неоднозначном исходе push запрещён повторный запуск без расследования удалённого состояния; существующие refs не переписывать.
