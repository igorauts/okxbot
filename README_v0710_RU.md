# OKX Grid Bot v0.7.10 — описание релиза

## Новые инструменты
BTC-USDT-SWAP, ETH-USDT-SWAP, SOL-USDT-SWAP, NEAR-USDT-SWAP, ZEC-USDT-SWAP, SUI-USDT-SWAP. Для каждого инструмента мастер читает `ctVal`, `ctValCcy`, `lotSz`, `minSz`, `tickSz` с OKX. Контракты и базовые монеты не тождественны.

## Торговая точность
`fmt()` теперь форматирует торговые цены и ключи уровней по инструментальному `PRICE_STEP` (`tickSz`) с сохранением совместимого представления для старых инструментов. Исправлен внутренний тест `run_tests()`, который использовал ключ `2500.00` для инструмента с большей точностью. Для SUI проверены реальные пять раздельных BUY с attached TP. UI `okx_ui074.py` теперь отображает малые GRID STEP, TP, защиту BUY и цену без ложного округления до $0.00.

## PANIC SELL
У новых экземпляров v0.7.10 сервис использует `ExecStopPost` с `okx_panic_cleanup0710.py`. После локального подтверждения `PANIC_DONE`, нулевой позиции, управляющей команды и совпадения каталога службы выполняется disable торговой службы и stop+disable привязанных Burst/Execution-наблюдателей. Для глобального Telegram-монитора команд нет. При неудавшемся или неполном PANIC обработчик ничего не отключает. В реальном тесте SUI отключение торговой службы подтвердилось, однако наблюдателей на этом экземпляре не было (`observers=0`); сценарий остановки двух **действующих** наблюдателей пока протестирован только с mock-systemd.

## Проверки и развёртывание
Тесты: 45 (`v076_checks`) + 13 (`v078_checks`) + 22 (`v079_checks`) + 19 (`v0710_checks`) = 99. Реальная торговля подтверждена для ZEC и SUI; NEAR проверена по публичной спецификации OKX, но её LIVE-тест не заявляется. Публикация не изменяет активные экземпляры ETH079, ZEC0710 и SUI0710-2.

`install.sh` в репозитории остаётся историческим и не устанавливает v0.7.10. Для развёртывания требуется отдельная проверенная процедура и подтверждение LIVE пользователем. Никогда не копируйте новый движок поверх файла уже торгующего экземпляра.
